# Дневник кормлений

Небольшое приложение для GitHub Pages. Оно хранит кормления только за текущий день в браузере одного устройства.

## Что умеет

- добавлять, изменять и удалять время и объём кормления;
- считать общий объём, количество кормлений и средний объём с 00:00 до 24:00;
- показывать время следующего кормления и обратный отсчёт;
- задавать интервал от 1 до 4 часов;
- проигрывать мягкий сигнал и показывать браузерное уведомление, пока приложение открыто;
- работать без интернета после первого открытия;
- автоматически удалять записи прошлого дня после полуночи.

## Где находятся данные

Записи находятся в локальном хранилище браузера (localStorage). Они:

- не отправляются в GitHub;
- не попадают в репозиторий;
- не синхронизируются между телефонами и браузерами;
- исчезнут при очистке данных сайта или браузера.

Настройки интервала сохраняются при переходе на новый день. Пароль не используется: человек, открывший ту же ссылку на другом устройстве, увидит собственный пустой дневник и не получит доступ к записям жены.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub, например baby-feed-journal.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В поле **Source** выберите **GitHub Actions**.
5. Отправьте код в ветку main.
6. Дождитесь завершения workflow **Deploy to GitHub Pages**.

Никакие ключи, пароли, базы данных и Repository secrets создавать не нужно.

## Установка на телефон

На Android откройте опубликованную ссылку в Chrome и выберите **Установить приложение** или **Добавить на главный экран**. После первого запуска приложение сможет открываться без интернета.

Чтобы разрешить уведомления:

1. Откройте настройки внутри дневника.
2. Нажмите **Разрешить уведомления**.
3. Подтвердите разрешение в браузере.

Важно: без сервера браузер не гарантирует сигнал после полного закрытия приложения. Мягкий сигнал надёжно работает, пока приложение открыто; в фоне Android может задержать таймер.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm test
npm run build
```

Готовая статическая версия появится в папке dist.
